# Independent protocol fixtures

Generated by `scripts/generate_protocol_fixtures.py` using Google's Python protobuf runtime and the generated message definitions from tronikos/androidtvremote2 commit `e664a8e1f14ee458b14c646bfb3ea46f10367051` (Apache-2.0). Its remote schema credits louis49/androidtv-remote, commit `0e82d72ec067b6452e0e2266720ba5e023821bf6` (MIT). See the root THIRD_PARTY_NOTICES.md.

`wire.properties` contains 31 serialized messages without their transport length prefix. They are independent of the application's Kotlin builder. Tests add framing and also cover multi-byte lengths, fragmentation and coalescing.

`synthetic-client.der` and `synthetic-server.der` contain public synthetic RSA certificates only. Their private keys are discarded during generation. `synthetic-crypto.properties` is a synthetic test PIN/digest vector generated with Python hashlib using the reference modulus/exponent/nonce algorithm. None of these files contain real TV credentials. They are test resources and are not packaged into the app APK.

Regeneration requires `protobuf` and `cryptography`, with the reference generated Python modules supplied in a separate directory. No reference application code is bundled in the production APK.
